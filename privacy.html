Ming Drive Uploader

Privacy policy

Effective October 20, 2026

Access and use

Ming Drive Uploader is a personal command-line utility used by its owner. It requests Google Drive access to verify the signed-in account, find existing destination folders, upload selected files, and optionally convert those files to Google Docs. Its Google Drive authorization permits reading and managing Drive files; operations are performed only for the owner's authorized tasks.

The personal Gmail draft helper requests Gmail compose access to verify the mailbox, create unsent drafts with selected attachments, and read those drafts back for verification. Google's compose permission also permits sending, but this helper implements no send operation. It refuses To, Cc and Bcc recipients, placing the intended address only in the draft's first body line. Test drafts may be deleted after verification; ordinary drafts remain for the owner to review.

Storage and sharing

The utility stores its Google authorization credentials in a private local cache on the owner's computer. Selected files are sent to Google Drive. The utility does not sell Google user data or provide it to advertisers. It does not itself send uploaded file content to an AI model. Separate tools the owner authorizes have their own data handling.

Google user data is used only for the requested personal file operations, consistent with the Google API Services User Data Policy, including its Limited Use requirements. This public website contains no uploaded documents or authorization credentials.

Retention and control

Files remain in the owner's Drive until the owner moves or deletes them. The owner can revoke the tool's access in Google Account third-party connections and remove the local credential cache. Revoking access does not automatically delete files already uploaded.

This website

These pages have no analytics, forms, advertising, or application cookies. GitHub Pages hosts them and may collect technical request information under the GitHub Privacy Statement.

Contact

For questions about this personal utility, contact its maintainer through the project repository. Do not post private files or credentials.
